# PinBoard 桌面置顶文本复制工具需求文档

## 1. 项目概述

PinBoard 是一款轻量级桌面置顶文本管理工具，用于在屏幕上固定展示常用信息，并支持快速复制。

用户可以将常用命令、代码片段、账号信息、配置参数、临时文本等内容保存到不同区域中，通过点击区域名称快速复制对应内容，提高信息获取效率。

---

# 2. 产品目标

## 2.1 核心目标

提供一个始终显示在桌面的信息面板，满足以下需求：

* 快速查看常用文本
* 快速复制指定内容
* 多区域独立管理不同类型信息
* 本地保存数据，无需联网
* 占用资源低，启动速度快

---

# 3. 功能需求

## 3.1 桌面悬浮窗口

### 功能描述

应用启动后显示一个悬浮窗口，并保持在其他窗口之上。

### 功能要求

* 支持窗口置顶
* 支持调整窗口大小
* 支持窗口拖动
* 支持关闭、最小化
* 支持设置页（标题栏 ⚙）：面板透明度、开机启动、鼠标穿透、数据文件路径等，便于后续扩展
* 支持可选开机自动启动（设置页开关，写入当前用户启动项）
* 支持鼠标穿透（设置页开关；主界面内容区穿透，设置页内可操作；标题栏始终可点）
* 支持自定义数据文件保存路径（设置页更改 / 恢复默认）
* 支持全局快捷键 `Ctrl + Shift + P` 快速显示/隐藏窗口（应用运行中生效；点 × 退出后失效）

---

# 3.2 多区域信息管理

## 功能描述

窗口内部支持划分多个独立区域，每个区域用于存放一类文本信息。

示例：

```
+--------------------------------+
| PinBoard                   - × |
+--------------------------------+
| Git（悬停提示：点击复制） [⤢][✎]|
| git pull                       |
|                                |
+--------------------------------+
| Docker                    [⤢][✎]|
| docker compose up -d           |
|                                |
+--------------------------------+
```

---

## 区域属性

每个区域包含：

| 字段     | 说明                                     |
| -------- | ---------------------------------------- |
| 区域名称 | 用于标识当前区域；点击名称复制该区域全文 |
| 文本内容 | 需要复制的信息                           |
| 显示行数 | 展示态可见行数；`0` 表示显示全部       |
| 放大入口 | 点击 ⤢ 将该区域铺满可视窗口；再点 ⤡ 退出 |
| 编辑入口 | 双击区域或点击 ✎ 进入编辑               |

---

## 区域操作

支持：

* 新增区域（头插，标题默认为空）
* 删除区域
* 修改区域名称
* 修改区域文本
* 调整区域显示行数
* 单区域放大铺满可视窗口（隐藏其他区域与新增栏）
* 调整区域顺序（拖动标题或空白处）

---

# 3.3 一键复制

## 功能描述

点击区域名称复制该区域文本。

操作流程：

```
用户点击区域名称
↓
读取当前区域文本
↓
写入系统剪贴板
↓
用户可直接粘贴
```

---

## 功能要求

* 每个区域只能复制自己的内容
* 不影响其他区域内容
* 复制成功后给予提示

例如：复制成功

* 悬停区域名称时，鼠标为手型，并显示复制提示浮层
* 正文仍可选中局部文字后使用系统快捷键复制（如 Ctrl+C）

---

# 3.4 数据持久化

## 功能描述

用户关闭应用后，数据不会丢失。

## 存储内容

包括：

* 区域名称
* 区域文本
* 显示行数
* 区域排序
* 窗口配置（尺寸、透明度、开机启动、鼠标穿透等）
* 数据文件路径偏好（保存在应用配置目录的 `config.json`，与数据文件分离）

示例：

```json
{
  "blocks": [
    {
      "title": "Git",
      "content": "git pull origin main",
      "displayLines": 0
    },
    {
      "title": "Docker",
      "content": "docker compose up -d",
      "displayLines": 4
    }
  ]
}
```

---

# 3.5 编辑模式

## 功能描述

支持用户修改区域内容与显示设置。

编辑方式：

* 双击区域进入编辑
* 点击 ✎ 进入编辑（与双击并存）
* 保存后恢复展示状态

编辑态可修改：区域名称、文本内容、显示行数（`0`=全部，`1–30`=限制行数）。

---

# 4. 非功能需求

## 4.1 性能要求

* 软件启动时间小于 3 秒
* 空闲状态低 CPU 占用
* 内存占用控制在 50MB 以内

---

## 4.2 运行环境

目标平台：

* Windows 10
* Windows 11

技术方案：

* Tauri 2
* Web 前端界面
* 本地文件存储

---

## 4.3 数据安全

所有数据保存在本地
